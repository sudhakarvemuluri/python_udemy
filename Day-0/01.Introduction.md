Compiler vs Interpreted.

--> Translation methods.
    1.Compiler
    2.Interpreter

    this can be described by an example like, chinese food menu in chinese language and chef knows only English.

    compiler:                                                          
    1) one time Translation
    2) Copy of receipe in English
    3) chef prepares after translation done completely.
    4) once translation done, chef prepares independently./ independent execution
    5) If there are any errors translation stops. 



    Interpreter:
    1) N times translation
    2) Receipe still in chinese
    3) preperation while translation
    4) Preperation with help / runtime environment
    5) partial preperation till the error

Interpreter Language:
Byte code
Runtime Environment

    --> Python .py file is first converted or compiled into .pyc file which is intermediate file.
    --> And that intermediate file .pyc can be executed or converted to machine level code in interpreter which is
         nothing but Python virtual machine.
    --> So called run time Environment.

Why it so important to convert into byte code, because it makes python platform independent and portable.

Programming Paradigms:
    --> procedural programming
    --> object oriented programming.
    --> Modular programming.
    --> Functional Programming.

procedural programming:
    used for developing bigger applications.
        we may have multiple lines of code, and we need to make sure that each and every line was correct and error free, maintaining that
        was complicated, So we may write those and divide the code into small functions or procedures so that we can write the code more
        efficiently and can be detected if any error arises and easy for enhancmnet acivities.

        And group of these functions can be called as modules, and also called as modular programming.

Object oriented Programming:

    We create a class and which is nothing but we are defining data variables and functions which are working to operate on those data variables.
    So by using those class as a blueprint we can use any number of objects which can use those functions which are defined in the class.
    By default python is object oriented programming and can supports Procedural programming.

Functional programming:
    It support mathematical function features and that is the reason python supports analysis on data and artifical intelligence.
